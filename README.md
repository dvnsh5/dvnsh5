## 🚀 Projects

### 🔹 [Churn Prediction](https://github.com/dvnsh5/churn-prediction)
Full classical ML lifecycle on the Telco Customer Churn dataset — EDA, feature engineering,
3 model comparison (Logistic Regression, Random Forest, XGBoost), Optuna hyperparameter
tuning, and error analysis, all tracked with MLflow.
**Tech:** Python, pandas, scikit-learn, XGBoost, Optuna, MLflow

### 🔹 [Image Classifier](https://github.com/dvnsh5/image-classifier)
CNN built from scratch vs. transfer learning with a pretrained ResNet18 on CIFAR-10 —
93.68% test accuracy via transfer learning vs. 64.26% from scratch. Includes per-class error
analysis and GPU-accelerated training.
**Tech:** PyTorch, torchvision, CUDA, MLflow

### 🔹 [Document Q&A (RAG)](https://github.com/dvnsh5/document-qa)
A fully local Retrieval-Augmented Generation system — PDF documents chunked, embedded, and
stored in a vector database, answered by a locally-served LLM (Llama 3.1 8B via Ollama).
3/3 retrieval accuracy on a held-out test set, zero API costs.
**Tech:** LangChain, ChromaDB, Sentence-Transformers, Ollama, MLflow

### 🔹 [Churn Prediction API](https://github.com/dvnsh5/churn-api)
Productionized the churn-prediction model as a containerized REST API — FastAPI for
validation and serving, Docker for portability. Includes an interactive Swagger UI and
tested high/low-risk customer predictions.
**Tech:** FastAPI, Docker, scikit-learn
